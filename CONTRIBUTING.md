# Contributing

This is an unreleased alpha. Open a focused issue with expected behavior,
actual behavior and reproducible steps. Remove account identifiers, home paths,
logs and game artwork before attaching evidence. Use synthetic fixtures.

Run the checks in docs/BUILDING.md. Keep changes small; preserve explicit IPC
validation and bounded file reads. Include a regression check for changed
behavior. Do not add Steam credentials, API keys, personal libraries or binary
assets without documented redistribution rights.

Submit only work you have the right to contribute. Contributions to original
project material are offered under MIT; preserve attribution and licenses for
any borrowed material and identify its exact source and modifications. No CLA
or transfer of copyright is required. Dependency changes must regenerate the
license inventory and review actual notices, not only SPDX declarations.
